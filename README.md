## Independent projects

Self-contained builds that run on synthetic data. Each one starts locally and carries its own tests.

- **[Backfill](https://github.com/Divuzki/postgres-backfill)** (Go, PostgreSQL): migrates 20,000 rows while old and new clients keep writing. The recorded run was interrupted, resumed and finished with zero mismatches.
- **[Field Ledger](https://github.com/Divuzki/field-ledger)** (React, Django, PostgreSQL): offline inspections that reconcile a supervisor's conflicting edit when the inspector reconnects.
- **[Meterbook](https://github.com/Divuzki/meterbook)** (DuckDB, Parquet, TypeScript): traces a cloud invoice to the teams that used it, to the cent.
- **[EvalGate](https://github.com/Divuzki/evalgate)** (Python, GitHub Actions): a release gate that caught an extraction regression hidden by better overall accuracy.
- **[GridShift](https://github.com/Divuzki/gridshift)** (Python, OR-Tools): schedules batch jobs around hourly power prices and a site power cap.
- **[Release Receipt](https://github.com/Divuzki/release-receipt)** (Python, Ed25519, CycloneDX): finds which deployments contain a withdrawn dependency, including after a rollback.
- **[Referral Relay](https://github.com/Divuzki/referral-relay)** (Python, SQLite, FHIR R4): a clinic referral queue whose message journal survives timeouts and duplicate responses.
